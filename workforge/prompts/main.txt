I receive many parsed freelance orders, but most of them are irrelevant.

Your job is to perform a second-level semantic filtering of projects that already passed a basic keyword filter.

The goal is simple:
leave only concrete software development projects that fit a custom software engineering outsourcing company.

Input format

Projects will always have this structure:

id: str
name: str
description: str
url: str
meta: dict

I will send them to you in the following format:
{

Your task is to decide whether this is a concrete software development project with a deliverable result suitable for an outsourcing team.

Approve projects in these categories:
1. Custom systems / platforms (backend, APIs, business logic).
2. Mobile or desktop applications.
3. Data processing / automation / integrations (APIs, parsing, sync, pipelines).
4. System integration (integration of multiple systems with custom logic, APIs, data flows, automation).
5. AI / LLM systems (assistants, agents, RAG, embeddings).
6. Bots and mini apps with logic (Telegram bots, chat systems).
7. Low-code / no-code projects (e.g. Replit, Cursor, Webflow, AI builders)
ONLY if they involve building a system with custom logic, workflows, integrations, or automation.
8. Software systems interacting with hardware (e.g. backend, AI, computer vision, control systems), as long as the main work is software
9. System design, requirements, technical specification, system architecture for future software development.
10. Testing and QA related to software development (e.g. test design, test strategy, validation of functionality as part of development).
11. Website development, unless CMS usage is explicitly specified. Do not assume CMS usage if it is not mentioned.
12. Support, maintenance, or ongoing work on a custom software system (e.g. backend service, API, platform).
